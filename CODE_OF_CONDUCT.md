# Código de conducta

Quienes participan en este proyecto se comprometen a mantener un entorno abierto, respetuoso y libre de acoso.

## Expectativas

Se espera que quienes colaboran:

- usen un lenguaje amable e inclusivo;
- respeten las opiniones y experiencias de las demás personas;
- acepten la crítica constructiva;
- antepongan el bien del proyecto al interés individual.

No se tolera:

- insultar, hostigar ni trolear a ninguna persona;
- divulgar información privada de terceros sin su permiso;
- cualquier conducta que resulte poco profesional en un entorno técnico.

## Ámbito

Este código se aplica en los espacios del repositorio (issues, pull requests y discusiones) y en cualquier lugar público donde alguien represente al proyecto.

## Aplicación

Los incidentes de abuso o conducta inaceptable pueden comunicarse al administrador del repositorio. Todas las quejas se revisan de forma justa y confidencial.

## Alcance

Este documento se redacta una única vez al inicio del proyecto. Los cambios de fondo requieren confirmación explícita de una persona; de forma autónoma solo se corrigen erratas o enlaces rotos.
